COMMAND: type ls
# Shows how the current shell resolves the ls command.
OUTPUT:
ls is hashed (/usr/bin/ls)

------------------------------------------------------------------------------
COMMAND: which ls
# Shows the executable path found for ls.
OUTPUT:
/usr/bin/ls

------------------------------------------------------------------------------
COMMAND: help ls
# Checks whether ls is a Bash builtin; status 1 is expected when it is external.
OUTPUT:
scripts/collect_evidence.sh: line 167: help: no help topics match `ls'.  Try `help help' or `man -k ls' or `info ls'.
